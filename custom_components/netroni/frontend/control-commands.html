Control systems over TCP

Connect a Crestron, Extron, Control4 or any other control system to the XP-Master. Send simple text commands to recall scenes and dim lights, and get a message back whenever something changes.

First switch it on in Home Assistant under Netroni → Settings → Network protocols, or in the Netroni app. We recommend setting a password there.

To try it, open a Telnet session from any computer on the same network:

$ telnet 192.168.1.20 23
Netroni XP-Master XPM-1A2B3C4D
login:
LOGIN mypassword
OK
SCENE 3 RECALL
~SCENE 3 "Evening" RECALLED
OK

The login: line only appears when a password is set.

  • It only works from the local network.
  • Up to 8 systems can be connected at the same time.
  • After 5 wrong passwords, that device has to wait a minute.
  • The connection can stay open as long as you like. Send PING to check it's still there.

The basics

  • Send one command per line. Capitals or not, it doesn't matter.
  • Each command gets OK back, or ERR with the reason.
  • Lines that start with ~ tell you how things are. They can arrive at any time, so read them whenever they come.
  • Put names with spaces in quotes: "Living room".

Scenes, groups and lights

Best in a programAlso works
Sceneits number: SCENE 3its name: SCENE "Evening"
Groupits number: GROUP 17its name: GROUP "Kitchen"
Lightits id: LIGHT 7144/1Tits name: LIGHT "Desk"

Use numbers and ids in your program: they don't change when someone renames something in the app, or when a device is replaced. A light's id is its XP-Mini and its port, for example 7144/1T. Send ?LIGHTS, ?GROUPS or ?SCENES to get the full list.

Numbers

  • Brightness and level are in percent, from 0 to 100.
  • Colour temperature is in kelvin, for example 2700.
  • To make a change gradual, add the seconds at the end: GROUP 17 ON 2.5.

Staying up to date

Whenever something changes, every connected system is told, no matter who made the change: the app, Home Assistant, a wall switch or another system.

~LIGHT 7144/1T "Desk" ON 40 2700
~GROUP 17 "Kitchen" ON 50
~SCENE 3 "Evening" RECALLED
~BUTTON AD2A "Hall" 1 PRESS
~MINI 7144 OFFLINE

A group can also be PARTLY on, when only some of its lights are on.

Tip: you get ~BUTTON every time a wall-switch button is pressed, even if it isn't set up to do anything. You can use those buttons for blinds, music or anything else.

Setting up your control system

  • Use a plain TCP client to the address and port above, and end each command with CR LF.
  • Split what comes back into lines.
  • If you set a password, send LOGIN first.
  • Then send ?ALL so your panels show the right state, and again after every reconnect.
  • Use the ~ lines to keep buttons and sliders in step with the lights.
